# smart-electrical-panel-guardian
Arduino based smart electrical panel monitoring and protection system 
Smart Electrical Panel Guardian

📌 Project Overview

Smart Electrical Panel Guardian is an Arduino-based monitoring and protection system designed to monitor electrical parameters and provide visual warnings when abnormal voltage or current conditions are detected.

🎯 Project Objective

The main goal of this project is to improve electrical safety by continuously monitoring voltage and current levels and alerting the user when the measured values exceed predefined limits.

⚙️ Features

* Voltage monitoring
* Current monitoring
* Real-time status indication
* RGB LED warning system
* LCD display for system information
* Automatic detection of abnormal electrical conditions

🧰 Components

* Arduino Uno
* LCD Display
* RGB LED
* Potentiometers
* Resistors
* Breadboard
* Jumper wires

💻 Software & Tools

* Arduino
* Tinkercad Circuits
* C/C++
* Arduino IDE

🔌 Circuit

🧠 How It Works

The Arduino continuously reads the voltage and current values from the input sensors. The measured values are compared with predefined safety thresholds.

The RGB LED indicates the current system status:

* 🟢 Green — Normal condition
* 🟡 Yellow — Warning
* 🔴 Red — Critical condition

The LCD displays the measured values and the current system status.
